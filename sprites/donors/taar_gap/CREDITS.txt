FORMAT VERIFICATION
-------------------
Every file was measured locally with PIL, not assumed. Numbers per file are in
../manifest.json, including the actual index range used — a PNG can declare a
large palette while using indices outside 0..15, and `to_4bpp`'s `& 0xF` mangles
that case silently.

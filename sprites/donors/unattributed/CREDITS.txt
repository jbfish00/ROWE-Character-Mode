============================================================

WHY THIS DIRECTORY IS SEPARATE
------------------------------
Both files below MEASURE PERFECTLY: 64x64, PIL mode "P", indices 0..14, stock
pokeemerald front-pic layout, drop-in injectable. Format is not the problem.

**Nobody can say who drew them.** They come from two personal forks of
rh-hideout/pokeemerald-expansion. Neither fork has a LICENSE file, neither has any
per-sprite credit, and the commit that introduced the art says only "add various
sprites". The upstream expansion ships no Colress front pic, so the art entered at
the fork and its trail ends there.

That is the same defect for which this workspace already rejected **SwSh Ultimate
Plus** as a primary source (CLAUDE.md: "rejected as primary — its README admits
unknown asset provenance"). It is strictly weaker than every set already staged:
  * Emerald Rogue      — no LICENSE, but a 42-name credits roll that travels with
                         the art
  * TAAR               — explicit free-to-use grant AND a named creator per folder
  * pokeemerald-platinum — no licence and no per-sprite credit, but at least a
                         single coherent project with a known team
  * here               — no licence, no project identity, no artist, no trail

ORIGIN SEARCH — what was tried and what it found
------------------------------------------------
Attempted attribution: GitHub commit history on both files (no credit), both repos'
whole file trees (no CREDITS/attribution file covering sprites — only the inherited
rh-hideout contributor roll, which is engine contributors, not this art), and a web
search for a Gen-3-style Colress artist.

The nearest named work is **aveontrainer's "Colress"** on DeviantArt
(https://www.deviantart.com/aveontrainer/art/Colress-786918192), described as
"Pokemon Team Plasma Boss Colress Overworld in FR/LG Style" and crediting
"PurpleZaffre for the color palette & the design I based it off of".
**It is NOT the source of these files** — it is 128x192, an OVERWORLD walk sheet,
not a 64x64 battle front pic. It also carries no explicit licence (DeviantArt
default terms only), so it is not usable on its own account either. Recorded here
so the next session does not re-run the same search.

VERDICT
-------
Colress is best described as **format-solved but attribution-unsolved**. Injecting
this would put art in the ROM that cannot be credited to anyone, which breaks
SPRITE_PLAN section 6's standing obligation. The choice is the user's:
  (a) ship it with an honest "artist unknown, via <fork>" credit, or
  (b) leave Colress without a front pic until a properly attributed sprite exists.
Nothing here has been staged into ROWE.
